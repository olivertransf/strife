# Strife

Pass-and-play life board. Two to four players share one screen, spin, and move a peg along a forked track. The bank is automatic.

```bash
pnpm install
pnpm test
pnpm dev
```

Open the dev server, seat the players, and play through retirement. The wealthiest player after house sales and the final tally wins.

Player peg art is from Kenney's Board Game Pack, CC0.

`packages/rules` is the game. `packages/client` is the table.
